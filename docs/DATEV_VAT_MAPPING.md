# DATEV VAT Mapping

## Overview

Explains how VAT is mapped to DATEV accounts for all supported tax cases.

| VAT Case       | SKR03 Account | SKR04 Account |
| -------------- | ------------- | ------------- |
| 19%            | 1576          | 1576          |
| 7%             | 1571          | 1571          |
| Reverse Charge | 1776/1577     | 1776/1577     |
| EU Acquisition | 3425          | 3425          |
| ...            | ...           | ...           |

## Special Cases

- Reverse charge: Both output and input VAT accounts are used.
- EU/International: Mapped per DATEV guidelines.

## Notes

- No VAT is recalculated during export.
- All mappings are reviewed by Steuerberater.
